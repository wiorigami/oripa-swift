# Original APK UI reference screenshots

Screenshots of the **original ORIPA for Android 0.2.3.3 APK** running on an Android
emulator (1080×2400 px, density 420 dpi → **1 dp = 2.625 px**). They were captured while
auditing the native port's UI against the APK (the authoritative visual reference; the
web port in `oripa-port` is itself a rebuild and deviates in a few places).

Files: projects/empty, paint (toolbars, action menu, add-method menu, line-type menu, FAB
mini menu), check, fold X-Ray / Cut Line / Overlap + their settings dialogs and the mode
dropdown, and the Settings screen.

These are reference-only screenshots of the GPL-3.0 ORIPA UI (the APK itself is not
redistributed). Measurement: dp = px / 2.625.
